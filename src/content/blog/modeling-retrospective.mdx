> 这是一篇参赛复盘：记录一次完整数学建模竞赛中的方法选择、实现与写作过程。

## 参赛与收获

2025 年的暑期建模和国赛 A 题备赛，是我第一次完整走一遍"**建模 → 求解 → 验证 → 写作**"的流程。准备阶段围绕国赛 A 题风格：连续/离散优化问题、数据量大、需要给出可复现的求解代码。

- C++ 实现的**模拟退火算法**：`annealing_experiment.cpp`（实验）与 `problem3_annealing.cpp`（第三问求解）；

- LaTeX 论文与原始数据。

## 为什么选模拟退火

A 题这类问题往往**解空间巨大、目标函数非凸**，梯度下降容易陷入局部最优。模拟退火的思想来自金属退火：高温时分子活跃、允许接受更差解，随温度下降逐渐"冷却"、只在更优方向移动。

核心是 **Metropolis 准则**：状态从 $x$ 转移到 $x'$ 后，若目标函数下降（极小化问题）则无条件接受；若上升，则以概率

$$P = \exp\left(-\frac{f(x') - f(x)}{T}\right)$$

接受。温度 $T$ 按降温策略 $T_{k+1} = \alpha \cdot T_k$（$\alpha$ 通常取 $0.9 \sim 0.99$）逐渐降低。

```cpp
// 核心循环（伪代码）
while (T > T_min) {
    // 在当前解邻域内随机产生新解
    auto x_new = neighbor(x);
    double delta = f(x_new) - f(x);
    if (delta < 0 || rand01() < exp(-delta / T)) {
        x = x_new;  // 接受新解
    }
    T *= alpha;     // 降温
}
```

## 关键实现细节

1. **邻域构造决定收敛速度**：对离散问题，邻域规则要考虑对称性，否则搜索空间会被"修剪"；
2. **初温与降温参数需要实验标定**：`annealing_experiment.cpp` 就是做这个的——对同一问题跑多组参数，对比收敛曲线；
3. **多轮重启**：单次退火有随机性，实践中要跑多轮取最优，并在论文中报告统计结果；
4. **结果可复现**：固定随机种子、记录完整实验配置，这是竞赛论文的基本要求。

## 关于写作

LaTeX 是数学建模论文的默认选择：公式排版、三线表、图表编号、参考文献管理都省心。这次的体验让我把 LaTeX 用进了后续所有课程项目（特征值报告的 `ctexart`、机械臂能耗报告的完整推导都在之后完成）。

## 复盘结论

- **算法选型 > 调参**：先想清楚问题结构（是否凸、是否连续、规模多大），再决定用精确算法、启发式还是规划求解器；
- **可视化是沟通的语言**：Mathematica 画的收敛曲线/解分布图，比数字表格更有说服力；
- **代码与论文一并交付**：评测者会跑你的代码，可复现性本身就是竞争力；
- 完整的流程（建模—求解—验证—写作）后来也延续到了我的数值计算项目里：**从零实现、验证精度、报告推导**，三者缺一不可。
